## Задача

Сделать так же, как с «Вывод форм CTP», для операции «Резка на печатный формат» (и других операций раздела Допечать → Резка): автоматически включать её в расчёт, чтобы не нужно было ставить галочку вручную.

## Что сделать

1. **`src/pages/Calculator.tsx`** — в существующий `useEffect` авто-включения добавить второй фильтр: операции с `category = "prepress"` и (`subgroup` содержит «резк» **или** `name` содержит «резк»). Количество берётся через текущую логику `defaultQty(op.unit)` — т.е. для единицы «лист» это `result.printSheets`, для «рез» — тираж, и т.д. Используем тот же механизм `userRemovedOpIds`, чтобы снятые вручную галочки не возвращались.

2. **`src/lib/calc/engine.ts`** — у движковой строки «Резка на печатный формат» (строка ~669) добавить условие: показывать её, только если `rule.cutCostPerSheet > 0`. Если цена в правилах = 0, строку отдаёт справочник операций (как теперь с формами), и двойного счёта не будет.

3. Тесты `src/lib/calc/engine.test.ts` запустить, убедиться что всё зелёное.

## Технические детали

- Рефакторить логику авто-включения внутрь одного `useEffect`: список матчеров (`{ predicate, qtyFn }`) → объединение с `extraOps`. Это сохранит существующее поведение для форм и добавит резку, без дублирования кода.
- `qtyFn` для резки: использовать ту же `defaultQty`-подобную функцию, что и в `ExtraOpsPicker` (по полю `unit`), — вынесу её в helper в Calculator.tsx, либо просто инлайн в эффекте через `baseResult.printSheets` для unit==="лист", иначе `baseResult.forms`/`circulation`.
