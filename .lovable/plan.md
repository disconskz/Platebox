## Цель
Дать менеджеру возможность переопределить автоматический выбор печатного/закупочного формата — либо доверять рекомендации, либо принудительно выбрать пару из справочника.

## Где добавляем UI
Шаг **4. Раскладка** в `src/pages/Calculator.tsx` (карточка уже есть, сейчас только показывает результат).

## UI
```text
[ Авто (рекомендовано) ]  [ Вручную ]    ← переключатель Tabs

Если "Авто":
  Текст: «Система выбирает оптимальную пару (печатный + закупочный) исходя из тиража и формата.»
  Показываем текущий выбор: 460×320 / 700×500 ★ Оптимально

Если "Вручную":
  Select «Печатный формат»  → список из formatPairs (помечены ★ рекомендованные = priorityPrintFormats)
  Select «Закупочный формат» → закупочные, привязанные к выбранному печатному
  Подсказка с метриками выбранной пары: шт/лист, шт/закуп, отходы, Δ к авто (+X ₸)
  Кнопка «Сбросить к авто»
```

## Логика
1. Новое состояние в Calculator: `manualPair: { print: PrintFormat; purchase: PrintFormat } | null` (default `null` = авто).
2. В `runCalculation` input передаём:
   - если `manualPair` задан → `formatPairs: [manualPair]` (engine использует ровно эту пару, ранжирование тривиально).
   - иначе — текущий список `formatPairs` как сейчас.
3. При смене продукта/формата/тиража — сбрасываем `manualPair` (или оставляем, если пара ещё валидна; проще — сбрасывать с тостом «Ручной выбор сброшен: параметры изменились»).
4. Сравнение «Δ к авто»: считаем оба варианта (авто и ручной) через `runCalculation` и показываем разницу `totalCost`.

## Изменения в коде
- `src/pages/Calculator.tsx`
  - state `manualPair`, helpers `availablePrintFormats`, `purchasesForPrint(printFormat)`.
  - В блоке `step === 4` — Tabs «Авто/Вручную» + два Select + блок метрик/Δ.
  - В `useMemo` для `result`: если `manualPair` — подменяем `formatPairs` на `[manualPair]`.
  - Параллельно держим `autoResult` (как сейчас) для расчёта Δ.
- Engine **не трогаем** — он уже корректно работает с произвольным списком пар.

## Edge-cases
- Изделие физически не помещается в выбранный ручной формат → показываем красный алерт «Изделие не вмещается, выберите другой формат», расчёт остаётся на авто.
- Для ручного выбора фильтр `priorityPrintFormats` НЕ применяем (иначе смысл ручного режима теряется).
- Альтернативы (`result.alternatives`) в ручном режиме скрываем — показываем только выбранную пару.
