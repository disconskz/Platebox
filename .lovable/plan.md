## План правок

1. **Зафиксировать бизнес-условия выбора печатного листа**
   - Для изделий, которые помещаются в диапазон A3+, оптимальный печатный формат должен выбираться только из «рабочих» форматов машины: `460×320` и `520×360`.
   - Дробные/теоретические форматы из раскроя закупочного листа (`500×350`, `250×700`, `350×333`, `360×345` и т.п.) оставить как альтернативы/технически возможные, но не выбирать по умолчанию, если есть рабочий формат.

2. **Переписать ранжирование раскладки в `engine.ts`**
   - Главный критерий: соответствие рабочему формату/машине и условиям тиража.
   - Затем: финансовая выгода — меньше закупочных листов, меньше печатных листов, меньше отходов.
   - Затем: максимум изделий на печатном листе.
   - Для `4+4`, `1+1` и других вариантов со «своим оборотом» сохранить требование чётного количества изделий на листе.

3. **Вернуть ожидаемое поведение для А5 и А6**
   - `А5`, тираж 1000, листовка, `4+4`: должен выбирать `460×320`, а не `500×350`.
   - `А6`, тираж 1000, листовка, `4+4`: должен выбирать рабочий формат по тем же правилам, а не длинный/нерациональный раскрой вроде `250×700`.
   - `520×360` должен оставаться допустимым, если он реально выгоднее или нужен по плотности/условиям.

4. **Починить список вариантов раскладки**
   - Показывать `460×320` и `520×360` в вариантах, даже если есть теоретические варианты с тем же количеством штук.
   - Теоретические/нерациональные варианты помечать как альтернативные, но не ставить `★ Оптимально`.
   - Если отходы больше 40%, такой вариант не должен становиться оптимальным по умолчанию.

5. **Добавить регрессионные тесты**
   - Тест на А5: выбран `460×320`.
   - Тест на А6: выбран рабочий формат, не `250×700`/не `500×350`.
   - Тест на список альтернатив: рабочие форматы присутствуют.
   - Тест на неэффективные варианты: отходы >40% не побеждают при наличии рационального рабочего формата.
