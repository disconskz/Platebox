## Проблема

В блоке «Операции из справочника → Допечать → Формы» строку «Вывод форм CTP» приходится отмечать вручную галочкой, чтобы она попала в расчёт. На скриншоте видно, что после ручного включения она корректно считается (4 формы × 500 ₸ = 2 000 ₸), но при каждом новом расчёте чекбокс снова пуст.

При этом в самом движке (`src/lib/calc/engine.ts`, строка ~665) уже есть автоматическая строка «Вывод печатных форм» с количеством `forms` и ценой `rule.formCost`. У пользователя `rule.formCost = 0`, поэтому реальная цена тянется только из справочника «Типы работ» через ручной чекбокс — отсюда и необходимость каждый раз отмечать.

## Что сделать

В `src/pages/Calculator.tsx` в компоненте `ExtraOpsPicker` (и в инициализации `extraOps` на уровне страницы):

1. Автоматически включать в `extraOps` операции, у которых `category = "prepress"` и `subgroup = "Формы"` (либо имя содержит «Вывод форм»), с количеством, равным `forms`. Это происходит один раз — при первой загрузке справочника операций и при изменении тиража/числа форм, но только если пользователь сам не снял галочку.
2. Хранить флаг «снято пользователем вручную» (`Set<string>` снятых id), чтобы автоповтор не возвращал галочку обратно, если пользователь её осознанно убрал.
3. В UI оставить чекбокс видимым, но по умолчанию он будет включён, а количество = `forms`. Цену по-прежнему берём из справочника `op.variable_cost`.
4. Чтобы избежать двойного счёта с движковой строкой «Вывод печатных форм», в `src/lib/calc/engine.ts` не добавлять автоматическую `prepress.push` для «Вывод печатных форм», когда `rule.formCost === 0` (т.к. её заменит позиция из справочника). Строку «Подготовка к печати» оставляем как есть.

## Технические детали

- Файл: `src/pages/Calculator.tsx` — добавить `useEffect`, который при загрузке `operations` находит prepress/Формы операции и мерджит их в `extraOps` (если id ещё не в `extraOps` и не в `userRemovedOpIds`).
- Файл: `src/lib/calc/engine.ts` — обернуть push «Вывод печатных форм» условием `if (rule.formCost > 0)`.
- Тесты `src/lib/calc/engine.test.ts` — при `formCost = 0` строки «Вывод печатных форм» быть не должно; при `formCost > 0` — должна быть.

Это уберёт необходимость вручную ставить галочку, при этом сохранит возможность снять её, если операция не нужна.
