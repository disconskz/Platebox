# Полная мобильная адаптация Platebox

Задача — довести каждый экран приложения до состояния, в котором им удобно пользоваться одной рукой на телефоне. Без упаковки в Capacitor/PWA — только адаптивная вёрстка.

## Что меняем

### 1. Глобальный мобильный каркас (`src/index.css`, `index.html`)
- Добавляем безопасные зоны для iPhone: `padding: env(safe-area-inset-*)` для шапок, нижних панелей и кнопок.
- `<meta name="viewport" content="..., viewport-fit=cover">`, `theme-color`, `apple-mobile-web-app-*` — чтобы статус-бар и нижняя зона выглядели нативно.
- Утилитарные классы: `.safe-top`, `.safe-bottom`, `.tap-target` (мин. 44px), `.no-scrollbar`, `.sticky-cta` (фиксированный нижний CTA с blur).
- На мобильном отключаем фоновую градиентную «бумагу» (тяжёлая для телефонов) — оставляем плоский фон.

### 2. Нижняя tab-навигация для приложения (новый `src/components/MobileTabBar.tsx`)
- Фиксированная нижняя панель (только `< md`): «Расчёты / Калькулятор / Аналитика / Справочники / Профиль».
- Активная вкладка подсвечивается, иконки + подписи 11px.
- Используется на `/app`, `/analytics`, `/references`, `/calculation/:id`. Убираем дублирующие кнопки из шапок на мобильном.
- Десктоп — сохраняет текущую верхнюю навигацию.

### 3. Лендинг (`src/pages/Landing.tsx`)
- Мобильное меню: бургер → выезжающий sheet с пунктами и CTA.
- Hero: уменьшаем размер заголовка (`text-[40px]`) и плотность, кнопки на всю ширину, гарантируем читаемость без горизонтального скролла.
- «Прайс-слип» в hero: на телефоне — 2×2 сетка вместо одной строки 4-up; список спецификации без лишних отступов.
- «Возможности»: вместо широкой 12-колонной строки — карточки 1-в-колонку с номером, заголовком и описанием.
- «Процесс»: карусель горизонтального скролла по шагам (snap), вместо 4-в-ряд.
- FAQ и финальный CTA: вертикальный стек, кнопки full-width, sticky CTA «Начать просчёт» внизу страницы только на мобильном.
- Footer: 1-колонка, центрировано.

### 4. Дашборд `/app` (`src/pages/Index.tsx`)
- Шапка: только логотип + меню (выйти). Кнопки «Аналитика/Справочники/Новый» переезжают в bottom-tab.
- Поиск становится sticky под шапкой.
- Карточки расчётов: уже есть мобильная версия — улучшаем (крупнее тапы, читаемые числа, бейдж шаблона, swipe-меню для удалить/дублировать через `Sheet`).
- Floating Action Button «+ Новый расчёт» (правый-нижний угол, над tab-bar).

### 5. Калькулятор (`src/pages/Calculator.tsx`, `Stepper.tsx`)
- На мобильном **итоги переезжают из правой колонки в нижнюю sticky-панель** (фиксированная над клавиатурой), где видны: себестоимость, маржа-слайдер, цена продажи. По тапу разворачивается полная карточка через `Sheet`.
- Stepper: компактный pill-индикатор «3 / 7 · Допечатные» + точки прогресса вместо горизонтальной полосы (она съедает экран).
- Кнопки «Назад / Далее» — фиксированы внизу, full-width, над клавиатурой.
- Поля шагов 1–5: переводим все строки `flex items-center gap-3` (чекбокс + лейбл + select + select) в вертикальный стек на мобильном (`flex-col sm:flex-row`), чтобы селекты не сжимались.
- Спецификация (шаг 6): на мобильном — карточки по этапам вместо горизонтально-скроллящейся таблицы.
- Превью раскладки (`LayoutPreview`) — сворачиваемая секция «Показать раскладку», по умолчанию скрыта на мобильном.

### 6. Просмотр расчёта (`src/pages/CalculationView.tsx`)
- Шапка: оставляем «Назад» + меню действий (`Sheet`) с пунктами «Excel / Дублировать / КП / История правок» — вместо четырёх кнопок в ряд.
- Карточка «Итоги» переезжает в sticky-низ на мобильном (как в калькуляторе).
- Спецификация: таблица → карточки на мобильном; редактирование цены — через bottom-`Sheet` с числовой клавиатурой (`inputMode="decimal"`).
- История правок: компактный список без таблицы.

### 7. КП (`src/pages/Quote.tsx`)
- Заголовок и метаданные — стек.
- Таблица позиций — мобильные карточки с тем же контентом; печатная вёрстка не меняется (ставим `md:` префиксы для перестройки).
- Кнопка «Печать / PDF» — sticky-bottom, full-width.

### 8. Аналитика (`src/pages/Analytics.tsx`)
- KPI: сетка 2×N на мобильном.
- Графики: высота 220px, легенда снизу, шрифты 10px; PieChart — без подписей внутри (они нечитаемы).
- Селектор периода переезжает над KPI отдельной строкой.

### 9. Справочники (`src/pages/References.tsx`)
- Tabs — горизонтальный скролл с snap, активная вкладка подсвечена.
- Таблица редактирования — на мобильном превращается в стек карточек: каждая запись = карточка с полями, действия «Сохранить / Удалить» внутри. Добавление новой записи — отдельная карточка-форма наверху или через FAB → `Sheet`.

### 10. Авторизация (`src/pages/Auth.tsx`)
- Карточка занимает всю ширину с padding, кнопки full-width, шрифты крупнее. Уже близко к мобильному — добавим safe-area и больше воздуха.

## Технические детали

- Брейкпойнт: всё по Tailwind `sm` (640px) и `md` (768px). Ничего ниже `sm` не должно требовать горизонтальный скролл, кроме явных carousel/snap-областей.
- Используем shadcn `Sheet` для bottom-sheet (правки цен, меню действий), `Drawer` — для развёртывания итогов калькулятора.
- Для FAB и нижних панелей — `position: fixed`, `bottom: calc(env(safe-area-inset-bottom) + 16px)`, z-index выше шапки.
- Все интерактивные элементы — минимум `h-11 w-11` (44pt) на мобильном.
- Числовые поля: `inputMode="numeric"` или `"decimal"` для нативной клавиатуры.
- Отключаем double-tap zoom через `touch-action: manipulation` на кнопках.

## Что НЕ меняем
- Бизнес-логика расчётов, схема БД, форматирование цены (уже унифицировано в ₸).
- Десктопные раскладки — сохраняем `lg:`/`md:` варианты «как есть».
- Печатная версия КП.
