## Доработка 28 — расчёт многополосной продукции

Объём ТЗ очень большой (18 пунктов, фактически новая форма расчёта для книг/блокнотов/ежедневников/журналов/каталогов/брошюр). Делать всё одним заходом рискованно — много логики в `engine.ts`, справочниках, БД и UI. Предлагаю разбить на 4 этапа, согласовать порядок и идти итерациями.

---

### Этап 1. Структура формы и базовые поля (UI + state)

Цель: подготовить каркас, ничего не ломая в существующем расчёте.

- Разделить `src/pages/Calculator.tsx` на **вкладки** (Tabs из shadcn):
  1. Основное
  2. Внутренний блок
  3. Обложка / крышка
  4. Скрепление
  5. Постпечатка
  6. Итог
- Вкладки 2–4 показывать только для типов: `book`, `magazine`, `brochure`, `notepad`, `calendar_*` (и каталог, если добавим).
- Добавить поле **«Количество страниц»** с валидацией (>0, кратно 2; предупреждение если не кратно 4/8/16).
- Состояние формы вынести в отдельные хуки/группы, чтобы вкладки не превращали файл в 3000 строк.

### Этап 2. Внутренний блок + расчёт толщины

- Блок «Внутренний блок»: бумага, плотность, толщина листа, цветность, формат, тип печати (офсет/цифра).
- Расширить справочник бумаги полем `thickness_mm` (миграция в `paper_materials` или аналоге — уточню по факту).
- Авто-расчёт: `листов = страницы/2`, `толщина блока = листов × толщина листа`. Показывать в UI.
- Подключить к существующему движку расчёта бумаги/печати внутреннего блока.

### Этап 3. Обложка, скрепление, доп. элементы

- Блок «Обложка/крышка»: мягкая/твёрдая/интегральная, бумага, плотность, переплётный картон, толщина картона, покровный материал, печать, ламинация, тиснение, УФ-лак.
- Блок «Скрепление» — единый селектор: скоба/евроскоба/КБС/термобиндер/шитьё/пружина мет./пружина пласт./твёрдый/мягкий. Управляет авто-маршрутом.
- Условные блоки:
  - **Пружина** (только если выбрана пружина): тип, цвет, диаметр (авто по толщине блока), шаг, расположение, длина навивки.
  - **Форзацы** (твёрдый переплёт): печать да/нет, бумага, плотность, кол-во (2 по умолч.).
  - **Каптал** (твёрдый): цвет, цена/м, кол-во (2).
  - **Ляссе** (ежедневник/книга): цвет, кол-во, цена/шт.
- Блок «Ламинация» расширить опциями (soft-touch, бархат, 1/2 стор.).

### Этап 4. Постпечатка, упаковка, авто-маршрут, итог

- Блоки: перфорация, скругление углов, тиснение (фольга/блинт/конгрев), УФ-лак, доп. элементы ежедневника (резинка, карман, петля, разделители, закладка, вставка), упаковка.
- **Авто-маршрут**: по `productType + bindingType` собирать список операций (как в п.17 ТЗ). Реализовать в `src/lib/calc/rules.ts` (или новом `routes.ts`) — функция `buildRoute(productType, binding, options) → SpecItem[]`.
- Вкладка «Итог»: себестоимость / наценка / НДС / цена за шт / детализация (уже есть `PriceBreakdownTree`, переиспользуем).
