## Цель

Добавить в **Базу знаний** (`src/pages/Knowledge.tsx`) полную информацию обо всех специализированных шаблонах изделий, появившихся в проекте: от Блокнота (доработка 60) до Этикетки (доработка 65). Сейчас в базе знаний есть только общие разделы (Калькулятор, Справочники, Правила расчёта, FAQ и т.д.) — про конкретные шаблоны там ничего нет.

## Что добавляю

Один новый верхнеуровневый топик **«Шаблоны изделий»** (`key: "templates"`), вставленный в массив `TOPICS` после `"calc"` (Калькулятор) и до `"multi-sku"`. Внутри — раздел-обзор и по одному раскрывающемуся блоку на каждый шаблон.

### Структура нового топика

1. **Обзор шаблонов** — зачем нужны отдельные шаблоны, чем отличаются от универсального калькулятора, общая логика (форма по аккордеонам → автомаршрут → спецификация → итог с НДС).
2. **Общие принципы**:
   - формула цены продажи: `Себестоимость + Наценка → ×1.16 НДС → /Тираж`;
   - автологика (premium → ламинация/тиснение/упаковка; высечка → удаление облоя; рулон → намотка/втулка; QR/переменные → цифра + ×1.5/1.6 контроль; прозрачный материал → белила);
   - коэффициенты сложности контура (×1.0 / ×1.3 / ×1.7 / ×2.0 / ×2.5);
   - `premiumCoef` (растёт от материала, ламинации, тиснения, сложности).
3. **По одному разделу на каждый шаблон**, каждый со своими полями, маршрутом и особенностями:
   - **Блокнот** (доработка 60) — блок, обложка, подложка, скрепление (пружина/скоба/КБС/термоклей), пружина-материал.
   - **Буклет / Евробуклет / Лифлет** — фальцовка, число сгибов.
   - **Брошюра / Каталог / Журнал** — блок + обложка, скрепление скобой/КБС, ламинация обложки.
   - **Книга мягкий переплёт** — блок, обложка, КБС/термоклей, форзацы (нет).
   - **Книга твёрдый переплёт** — книжный блок, форзацы, марля, каптал, переплётная крышка, ригель.
   - **Ежедневник** — блок, обложка, тиснение, ригель, ляссе, скругление углов.
   - **Кубарик / блок** — склейка, подложка.
   - **Календарь квартальный** — пружина, шапка, блок, подложка.
   - **Календарь-домик** — обложка, биговка, склейка.
   - **Календарь карманный** (доработка 63) — формат, сетка, ламинация, скругление углов.
   - **Открытка** (доработка 61) — биговка, сложение, премиальная отделка, фигурная высечка.
   - **Папка** (доработка 62) — конструкция (карманы, корешок, клапаны, резинки, кольца), биговка, высечка, склейка, фурнитура (люверсы, магниты).
   - **Грамота / Диплом** (доработка 62.1) — дизайнерские бумаги, нумерация, QR, тиснение, конгрев, фольгирование, комплектовка с папкой/рамкой/паспарту.
   - **Наклейка / Стикер** (доработка 64) — самоклейка, лист/рулон, контурная резка, плоттер, надсечка, выборка, ламинация, премиум-стикеры, UV DTF, голография.
   - **Этикетка** (доработка 65) — рулонные/листовые, штрихкоды, QR, нумерация, дата/срок/партия/S/N, высечка, выборка, намотка с втулкой 25/40/76 мм, ручьи, контроль кодов.
4. **Когда какой шаблон выбирать** — короткая шпаргалка-таблица: продукт → шаблон → ключевая логика.
5. **Что общего и что разное** — сравнение Наклейка vs Этикетка, Брошюра vs Каталог vs Журнал, мягкий vs твёрдый переплёт.

### Технические детали реализации

- Файл: только `src/pages/Knowledge.tsx`. Один локализованный патч — вставка нового объекта `Topic` в массив `TOPICS`. Никаких других файлов трогать не нужно.
- Использую существующие компоненты `Accordion / AccordionItem / AccordionTrigger / AccordionContent`, разметку `ul/ol/p/code/b` и стиль уже принятый в файле.
- Каждому разделу — уникальный `id` (`tpl-notepad`, `tpl-card`, `tpl-folder`, `tpl-diploma`, `tpl-pocket-calendar`, `tpl-sticker`, `tpl-label`, `tpl-overview`, `tpl-common`, `tpl-when`, `tpl-vs`), чтобы работали ссылки через `#hash` (логика автоматического открытия по хешу уже есть в файле).
- Без изменений в маршрутах, сайдбаре, БД, секретах.
