## Доработка 5. Объединить «Биговка ручная / Фальцовка машинная / Фальцовка ручная» в одну позицию «Кол-во сгибов на изделии»

Сейчас в справочнике это три отдельные операции (categories «Биговка»/«Фальцовка»), и в `ExtraOpsPicker` они показываются тремя строками с галочками. Нужно скрыть их из стандартного пикера и заменить одним блоком с выпадающим списком количества сгибов; цена за сгиб выбирается **автоматически по плотности бумаги**:

- плотность ≤ 150 г/м² → фальцовка, **1 тг / сгиб**;
- плотность > 150 г/м² → биговка, **2 тг / сгиб**.

Реализация:

- `src/pages/Calculator.tsx`:

  - В `extraSpecItems`/`result` добавить новый `useMemo foldItems`, который при `foldsPerItem > 0` возвращает один `SpecItem`:

    - `unitPrice` = 1 или 2 (в зависимости от `effectiveMaterial.density`),
    - `unit: "сгиб"`.
  - Удалить из `ExtraOpsPicker` операции справочника c `category in ('Биговка','Фальцовка')` (фильтровать на входе по `op.subgroup`/`op.category`), чтобы не дублировались.

## Доработка 7. Объединить все виды высечки в одну позицию «Высечка» с авто-ценой по материалу

В справочнике три записи («Высечка после печати», «Высечка на буше», «высечка без печати»), плюс жёстко зашитый блок в `engine.ts` (стр. 570–573). Нужно одна универсальная позиция «Высечка» с автоформулой и выбором штампа.

Цены по материалу (определяются по `material.type` / `material.subgroup`):

| Материал | Цена за лист | Приладка |
|---|---|---|
| картон | 5 ₸ | 5000 ₸ |
| микрогофра | 10 ₸ | 5000 ₸ |
| поролон | 20 ₸ | 5000 ₸ |
| переплётный картон | 10 ₸ | 5000 ₸ |
| пластик | 7 ₸ | 5000 ₸ |

Формула: `высечка = печ_листов × цена_по_материалу` + отдельная строка «Приладка высечки» (5000 ₸) + при выборе «новый штамп» отдельная строка «Изготовление штампа» с ценой, которую вводит менеджер.

Реализация:

- `src/pages/Calculator.tsx`:
  - Добавить state: `dieCutEnabled: boolean`, `dieCutStampMode: "existing" | "new"`, `dieCutStampCost: number` (по умолчанию 0).
  - Добавить в карточку «Послепечатные операции» блок «Высечка» (для всех типов продукции, не только bag/diecut): чекбокс «Высечка», `Select` «Штамп: есть готовый / изготовить новый», и при «новый» — поле «Стоимость штампа, ₸».
  - В новом `useMemo dieCutItems` собирать `SpecItem[]`:
    - «Высечка» — `qty = printSheets`, `unit: "лист"`, `unitPrice` по таблице (`pickDieCutPrice(material)`), `total = printSheets × price`;
    - «Высечка (приладка)» — `qty 1, unit "шт", unitPrice 5000`;
    - «Изготовление штампа для высечки» (только если `dieCutStampMode==="new"` и `dieCutStampCost>0`) — `qty 1, unit "шт", unitPrice = dieCutStampCost`.
  - Добавить хелпер `pickDieCutPrice(material)` — `switch` по нормализованному `material.type/subgroup`. Если материал не распознан, дефолт 5 ₸ + предупреждение в `warnings`.
  - Скрыть из `ExtraOpsPicker` операции с category «Высечка»/«Высечка на буше»/«выдергивание после высечки», чтобы не было двойного учёта.
  - Удалить старый чекбокс «Высечка» (стр. 1954–1959) и блок `hasDieCut` в `engine.ts` (стр. 570–573).
