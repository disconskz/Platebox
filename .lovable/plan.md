## Цель

На странице «Новый расчёт» (`src/pages/Calculator.tsx`) добавить кнопку **«Применить шаблон»**, через которую менеджер может выбрать один из своих сохранённых шаблонов и подставить его параметры в текущую форму, не уходя на главную.

## Как сейчас

- В БД есть `calculations.is_template = true` — расчёты-шаблоны.
- На главной (`Index.tsx`) уже есть кнопка «Создать из шаблона», которая ведёт на `/calculator?from=<id>`.
- В `Calculator.tsx` (строки 1980–2001) уже работает загрузчик по `searchParams.get("from")` — он подставляет product_type, тираж, формат, красочность, материал, оборудование, наценку и показывает тост «Загружен шаблон».

Не хватает только UI, чтобы переключать шаблон **изнутри** калькулятора.

## Что делаю

1. **Новый компонент** `src/components/calc/TemplatePicker.tsx`:
   - Кнопка «Применить шаблон» с иконкой `Sparkles` (variant outline, size sm).
   - При открытии — `Popover` с `Command` (поиск + список) в стиле существующих селекторов калькулятора.
   - Загружает `calculations` пользователя: `is_template = true`, сортировка по `updated_at desc`, ограничение 100.
   - У каждой строки показывает: название шаблона, маленький мутный подпис «{тип продукции} · {тираж} шт».
   - Состояние пустого списка: «Сохранённых шаблонов нет. Сохраните расчёт как шаблон на главной».
   - При выборе вызывает проп `onPick(id)`.

2. **Встраиваю в `Calculator.tsx`**:
   - Импорт компонента.
   - В шапке (строки 4897–4916, блок `ml-auto flex items-center gap-2`) рядом с `AiOrderAssistant` добавляю `<TemplatePicker onPick={(id) => setSearchParams({ from: id })} />`.
   - Существующий `useEffect` по `searchParams` сам подхватит изменение и применит шаблон + покажет тост «Загружен шаблон». Никаких новых редьюсеров.

3. **Обновление Базы знаний** (`src/pages/Knowledge.tsx`, топик `calc`, секция `calc-save`): короткое примечание, что шаблон теперь можно применить прямо в калькуляторе через кнопку в шапке.

## Что НЕ делаю

- Не меняю схему БД, RLS, маршруты.
- Не меняю логику загрузки шаблона (она уже есть и работает).
- Не трогаю отдельные специализированные калькуляторы (Notepad, Sticker и т.д.) — у них своя архитектура; универсальный `Calculator.tsx` — единственная страница «Новый расчёт» в сайдбаре, как видно на скриншоте.
