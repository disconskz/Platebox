## Цель

Улучшить страницу «Справочники» (`/references`): добавить пагинацию по 15 записей на страницу во все таблицы справочников (Бумага, Операции, Оборудование, Ламинация, Константы).

## Что меняется

Все правки — в одном файле: `src/pages/References.tsx`, в компоненте `RefTable` (он используется для всех 5 справочников, поэтому одно изменение покрывает все таблицы).

### 1. Состояние пагинации

Добавить в `RefTable`:
- константу `PAGE_SIZE = 15`;
- `useState<number>` для текущей страницы;
- сброс страницы на 1 при смене вкладки (`spec.key`) и после успешного добавления новой записи.

### 2. Срез данных

С помощью `useMemo` считать:
- `totalPages = ceil(rows.length / 15)` (минимум 1);
- `currentPage` с защитой от выхода за границы (на случай удаления последней записи на странице);
- `pageRows = rows.slice((currentPage-1)*15, currentPage*15)`;
- индексы `fromIdx`–`toIdx` для подписи «Показаны N–M из K».

В `<tbody>` рендерить `pageRows` вместо `rows`. Строка-черновик «добавить новую запись» остаётся всегда наверху, независимо от страницы.

### 3. UI пагинации

Под таблицей, в `CardContent`, добавить компактный блок:

```text
[ Показаны 1–15 из 42 ]            [‹]  1 / 3  [›]
```

- Слева — счётчик записей (или «Нет записей» когда пусто).
- Справа — две кнопки `Button size="sm" variant="outline"` с иконками `ChevronLeft` / `ChevronRight` из `lucide-react` и индикатор «страница / всего».
- Кнопки `disabled` на крайних страницах.
- Блок: `flex flex-wrap items-center justify-between gap-2`, `text-xs text-muted-foreground` — корректно ужимается на мобильных.

### 4. Пустое состояние

Если записей нет — показывать строку «Нет записей» внутри `<tbody>` (под строкой добавления), чтобы таблица не выглядела «обрезанной».

## Технические детали

- Пагинация полностью клиентская: данные уже грузятся одним запросом `select("*")`, серверный пейджинг не нужен — справочники небольшие.
- Сортировка сохраняется (`order(spec.cols[0].k)` в `load()`).
- Импорт: добавить `useMemo` и иконки `ChevronLeft`, `ChevronRight`.
- Шаг изменения PAGE_SIZE в будущем — одна константа.

## Что НЕ меняется

- Логика CRUD (`add`, `save`, `remove`, `update`) и схема данных.
- Шапка страницы, табы, `HelpHint`, мобильный таб-бар.
