## Цель
В блоке «Раскладка» (компонент `LayoutPreview`) сейчас каждое изделие на листе показывается одинаковым прямоугольником с номером. Заменим это на стилизованную мини-иллюстрацию изделия в зависимости от `productType` — чтобы было видно, что именно печатается (календарь, блокнот, визитка, пакет, стикер и т.д.).

## Что меняем

### 1. Новый компонент `src/components/calc/ProductGlyph.tsx`
SVG-«глиф» изделия, который рисуется внутри уже рассчитанной ячейки раскладки. Принимает:
- `type: ProductType`
- `x, y, w, h` — координаты и размеры ячейки в координатах SVG листа
- `index` — номер на листе

Внутри один `<g>` с фоном (мягкая заливка), рамкой и тематическим орнаментом. Номер ставится в углу мелко, а не по центру, чтобы не перекрывать рисунок.

Набор глифов (минималистичные, монохромные, в hsl(var(--primary))):
- `leaflet`, `leaflet_diecut`, `blank`, `selfcopy` — лист с тремя горизонтальными линиями текста.
- `booklet`, `brochure` — лист с вертикальной линией сгиба.
- `businesscard` — карточка с двумя короткими линиями (имя/телефон).
- `sticker`, `sticker_diecut`, `label` — скруглённый прямоугольник с пунктирным контуром по периметру (контур высечки).
- `bag` — пакет: трапеция корпуса + две дужки-ручки сверху.
- `envelope` — прямоугольник с треугольником-клапаном.
- `box` — развёртка коробки (крест из 4 клапанов).
- `folder` — папка с язычком сверху.
- `poster` — лист с большим заголовком и блоком линий.
- `notepad` — блокнот: вверху ряд кружков-пружины, ниже линии.
- `book` — книга: две страницы со сгибом по центру.
- `magazine` — обложка: крупный блок (фото) сверху + линии заголовка.
- `calendar_wall` — сетка 7×3 + шапка с месяцем.
- `calendar_desk` — горизонтальный с подставкой (треугольник снизу).
- `calendar_quarter` — три блока сеток друг под другом.
- `wobbler` — круг/овал на тонкой ножке.
- `shelftalker` — длинный горизонтальный с язычком справа.
- `kubus` — куб (изометрия из трёх граней).

Глиф автоматически масштабируется под размер ячейки и поворот (`rotated`). Если ячейка слишком маленькая (< ~15мм по меньшей стороне) — рисуется упрощённая версия (просто рамка + номер).

### 2. Правка `src/components/calc/LayoutPreview.tsx`
- Принять новый prop `productType: ProductType`.
- В цикле раскладки вместо текущих `<rect>` + центрального номера вызывать `<ProductGlyph type={productType} x={x} y={y} w={itemW} h={itemH} index={n} />`.
- Bleed-подложка (тёплая жёлтая зона) остаётся как есть.

### 3. Правка `src/pages/Calculator.tsx` и `src/pages/CalculationView.tsx`
Передать `productType` в `<LayoutPreview ... productType={input.productType} />` (везде, где компонент используется).

## Технические детали
- Все SVG элементы используют существующие токены: `hsl(var(--primary))`, `hsl(var(--muted-foreground))`, `hsl(var(--warning))` — без хардкода цветов, чтобы корректно работало в светлой и тёмной теме.
- Глифы строятся в локальной системе координат `0..w / 0..h` (через nested `<svg x y width height viewBox="0 0 100 100" preserveAspectRatio="xMidYMid meet">`), чтобы код каждого глифа был размер-независимым.
- Поворот изделия (`rotated`) уже учитывается тем, что `w`/`h` ячейки приходят уже перевёрнутыми; для книжных глифов (книга, блокнот) ориентация определяется отношением `w/h`, и сгиб/пружина рисуется по нужной стороне.
- Никаких изменений в расчётах/раскладке — только визуальный слой.
